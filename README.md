# MLOps Training

This repository tracks my hands-on learning in machine learning, MLOps, and
DataCamp. It will contain course notes, experiments, and projects that take
models from exploration to production.

## Learning path

### 1. Machine learning foundations

- [ ] Complete DataCamp's [Machine Learning Scientist in Python](https://www.datacamp.com/tracks/machine-learning-scientist-with-python) career track
- [ ] Practice data preparation and feature engineering
- [ ] Train and evaluate supervised and unsupervised models
- [ ] Study deep learning, NLP, and time-series modeling

### 2. Production machine learning

- [ ] Complete DataCamp's [Machine Learning Engineer](https://www.datacamp.com/tracks/machine-learning-engineer) career track
- [ ] Track experiments and models with MLflow
- [ ] Version datasets and pipelines with DVC
- [ ] Package services with Docker
- [ ] Add automated tests and CI/CD
- [ ] Deploy and monitor a model
- [ ] Detect data drift, concept drift, and model degradation

## Project standard

Each project should eventually include:

- a clear problem statement and dataset description
- reproducible data preparation and training code
- experiment and model tracking
- automated tests
- a prediction API or batch inference pipeline
- containerization and CI/CD
- model and data-quality monitoring
- setup and usage instructions
